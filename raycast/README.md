# Raycast script commands

Switch the terminal colour theme without opening a terminal.

## Setup

Once, in Raycast: **Settings → Extensions → + → Add Script Directory**, and
pick this folder (`~/.dotfiles/raycast`).

Raycast picks up new scripts automatically afterwards, so adding a theme
later needs no further setup.

## Commands

One command per theme — open Raycast, type the theme's name, press enter:

| Command | |
|---|---|
| 🌊 **Kanagawa** | 🌹 **Rosé Pine** |
| 🌃 **Tokyo Night** | 🌲 **Everforest** |
| 🍂 **Gruvbox Material** | |

Plus two helpers:

| Command | What it does |
|---|---|
| 🔄 **Cycle Terminal Theme** | Step to the next theme — good on a hotkey |
| ♻️ **Reload Terminal Theme** | Re-apply the current theme, e.g. after changing macOS appearance |

The per-theme commands run in `silent` mode: Raycast closes immediately and
shows nothing on success, and surfaces the error if the switch fails.

## Editing

`theme-<name>.sh` files are generated by `theme-generator/raycast.py`, which
runs as part of `theme-generator/apply.py`. Change the generator, not the
scripts. `theme-cycle.sh` and `theme-reload.sh` are hand written and read the
themes directory, so they need no regeneration.
